Connect to read CTS / DCD / DSR / RI.

VyomSAT guide defaults: 9600 baud, 8 data bits, no parity, 1 stop bit, and no flow control.

The current firmware dispatches a buffered command when CR or LF arrives, so CR+LF remains the safe VyomSAT default.

Quick commands use the current VyomSAT firmware table by default and can be customised from the sidebar gear controls. Terminal logs can be saved with Download log.
